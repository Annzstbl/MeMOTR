# model_20260511_gmc

从 `20260511` 复制；**推理**时在 `get_reference_points` 之前用 GMC 更新已有 track 的 `ref_pts`（`apply_gmc_to_track_refs`，仅 `eval` 且传入 `gmc`）。

## 代码改动摘要

- `forward` 在 `get_reference_points` 前调用 `apply_gmc_to_track_refs`
- `ref_pts` 按 **有效区域 (H,W)**（非 pad 尺寸）↔ 像素 ↔ `compensate_rotated_boxes`（le135 四顶点仿射）↔ 写回 `inverse_sigmoid`
- 检测 query 的 reference 不变；**训练**不使用 GMC
- Submit 推理走 `_run_with_prior_map`（需 `SCEM.PRIOR_MODE` 非空，父配置 `20260511-1.yaml` 为 `gate`），并传入 `gmc`

## 配置

| 项 | 路径 / 值 |
|----|-----------|
| 评测 yaml | `configs_hsmot_spectral_embed_252/20260511-1-gmc-submit.yaml` |
| 权重（只读） | `SUBMIT_CHECKPOINT_DIR` → `.../20260511-1-99/stage2_mot` |
| 评测输出 | `SUBMIT_OUTPUT_DIR` → `.../20260511-1-gmc-252` |
| 模型版本覆盖 | `MEMOTR_VERSION: '20260511_gmc'` |

## 说明

- `main.py --mode eval` 为 **DanceTrack/MOT17 等** 的 `eval_engine` 流程，**不是** 本仓库 hsmot TrackEval；hsmot 252 请用上面的 `batch_submit_eval_hsmot_gmc_ckpts.py`。
- GMC 在 submit 中与训练一致：`sparseOptFlow`、pad 后 tensor 上估计仿射，再更新 track `ref_pts`。
- 权重目录勿写入评测结果；`SUBMIT_OUTPUT_DIR` 与 `SUBMIT_CHECKPOINT_DIR` 已分离。
